# Stream Savvy

PROMPT PARA IA DE DISEÑO WEB

Quiero que diseñes y estructures una página web moderna, elegante, tecnológica, minimalista pero visualmente impactante, pensada para organizar y comparar precios de diferentes apps y servicios de streaming, además de otros tipos de stock como trámites. La web debe ser clara, muy ordenada y fácil de usar, con una experiencia visual premium.

Objetivo principal

Necesito una página donde pueda ver comparados los precios de cada app de streaming según el grupo o vendedor que la ofrece, para no tener que entrar grupo por grupo en WhatsApp. La idea es que yo pueda seleccionar una app, por ejemplo Netflix, y ver dentro de esa sección todos los grupos o vendedores que la ofrecen, con sus precios ordenados de menor a mayor.

Estructura general

La página debe estar organizada por categorías principales, por ejemplo:

Streaming

Trámites

Otros servicios o productos si después se agregan

Dentro de Streaming, cada app debe tener su propio botón o tarjeta con su color característico:

Netflix: rojo

Disney+: azul

VIX: naranja

Y así con cada app, asignando un color identificable para cada una

Al entrar a una app, debe mostrarse toda la información ordenada en listas comparativas.

Cómo debe mostrarse cada stock

Cada registro debe incluir:

Nombre de la app o servicio

Tipo de perfil o producto

Duración del plan o stock

Nombre del grupo o vendedor

Precio

Tipo de stock o detalle adicional si existe

Fuente del stock si aplica

Ejemplo visual:

Netflix Perfil 1 mes

Grupo: Juan Pérez

Precio: $40

Detalle: Hits

Orden de precios

Toda la información debe mostrarse de arriba hacia abajo del precio más barato al más caro.

Esto debe aplicarse en cada categoría y en cada app, siempre que estén en la misma duración.

Separación por duración

Como habrá stock de diferentes tiempos, necesito que se acomode así:

1 mes

2 meses

3 meses

anual

multimes

Primero deben mostrarse los planes de 1 mes, después los de más duración.

Los planes de más meses deben compararse entre sí, pero sin mezclarse de forma injusta con los de 1 mes, para que la comparación sea clara y lógica.

Diferencia entre tipos de grupos

La web debe distinguir claramente entre dos tipos de stock:

1. Grupos donde sí estoy dentro

Estos son grupos que yo ya sigo o en los que ya estoy incluido.

Aquí debe mostrarse:

Nombre del grupo

Stock disponible

Precio

Detalle del producto

2. Grupo de venta libre

Estos son grupos donde la gente publica lo que vende, pero yo no estoy dentro del grupo.

En estos casos debe mostrarse de forma visualmente distinta, con un encabezado tipo:

Grupo de Venta Libre

Y debajo debe aparecer:

Nombre de la persona o vendedor

Número de teléfono completo

Producto ofrecido

Precio

Cualquier nota o detalle adicional

La idea es que se vea primero el nombre grande del grupo o categoría, y debajo el teléfono o contacto, para identificar claramente de quién es la oferta.

Trámites

También habrá stock de trámites, y como puede haber muchos tipos diferentes, quiero que tú propongas la mejor forma de categorizarlos.

Si no encajan en una sola lista, quiero que los organices en subcategorías claras y fáciles de entender.

Debes proponer una estructura inteligente para ordenar esos trámites de forma limpia, sin que se vea saturada.

Diseño visual

El diseño debe cumplir con estas características:

Muy moderno

Elegante

Minimalista, pero no simple

Estilo tecnológico

Visualmente atractivo

Fácil de navegar

Con buen uso del color

Con tarjetas limpias y bien separadas

Con tipografía clara y premium

Con buen contraste para leer precios rápido

Con sensación de dashboard o panel profesional

Funcionalidad deseada

Quiero que la página permita:

Buscar una app o servicio

Filtrar por duración

Ordenar por precio

Ver el vendedor o grupo

Ver el detalle del stock

Distinguir entre grupo interno y venta libre

Ver colores por app

Navegar de forma rápida y organizada

Prioridad de organización

La prioridad absoluta es que la página esté:

Muy bien organizada

Fácil de comparar

Visualmente bonita

Rápida para encontrar el mejor precio

Clara al separar tipos de stock

Instrucción final

Necesito que no solo hagas el diseño, sino que también propongas la mejor estructura posible para que esta página crezca con muchos datos sin volverse confusa. Quiero que pienses como diseñador UI/UX y como organizador de información.

A continuación te daré los grupos en los que si estoy unido

```sh
git clone <this-repository-url>
cd <repository-name>
npm i

```
